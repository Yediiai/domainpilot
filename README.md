# DomainPilot — Next.js Domain & Web Infrastructure Landing Page Application

A modern, developer-focused SaaS landing application for domain registration, enterprise Anycast DNS, automated SSL, and cloud infrastructure management.

## 🚀 Port & Development

This application runs on port **9001**:

```bash
npm install
npm run dev
```

Visit: `http://localhost:9001`

## 📄 Pages Included (4 Fully Designed Pages)

1. **Home / Landing Page (`/`)**:
   - Hero section with live interactive domain availability search
   - Trending TLD pricing badges (`.com`, `.io`, `.dev`, `.ai`, `.tech`)
   - Platform infrastructure highlights (Anycast DNS, 100% SLA)
   - Interactive Domain Transfer Savings Calculator
   - Customer testimonials and technical FAQs
2. **Domains & Pricing (`/pricing`)**:
   - Domain extension pricing table with category filters & instant search
   - Transparent registration, renewal, and transfer rates
   - Standard inclusions (Free WHOIS privacy, 1-click DNSSEC, Anycast routing)
3. **Features & Infrastructure (`/features`)**:
   - 24-PoP Global Anycast DNS with sub-10ms query resolution
   - Automated Let's Encrypt / DigiCert SSL certificates
   - Developer APIs & Terraform provider code switcher with 1-click copy
   - Enterprise security, 2FA hardware keys, and audit log streaming
4. **About & Contact (`/about`)**:
   - Company mission and wholesale pricing philosophy
   - ICANN accreditation & SOC2 compliance certifications
   - Technical Support Ticket Form with React Hook Form + Zod validation

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Dark Navy & Electric Blue theme)
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod validation
